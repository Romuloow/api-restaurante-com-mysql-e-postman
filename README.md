# CÓDIGO SIMULANDO A API DE UM RESTAURANTE
## Descrição
Esse é um código que criei para praticar a criação de APIs com nodejs. Nesse código, eu simulei uma API de um restaurante que se conectao a um banco de dados MySQL,
criando tabelas e inserindo dados.

## Como usar o modelo
1. No diretório do código, digite "npm i" para instalar os pacotes utilizados.
2. Crie um banco de dados no mysql e passe as informações no arquivo "conexao.js", no caso a senha, usuário, e etc...
3. Utilize o postman para fazer o GET, POST, DELETE e PATH de acordo com a rota presente nos "controllers"
4. Dê um "npm start" no terminal para rodar o servidor
